# Akkhara စုစည်းမှု အမျိုးအစားများ (Collections)

Akkhara တွင် "array" ဟု ခေါ်နိုင်သည့် တန်ဖိုးအမျိုးအစား **၅ မျိုး** ရှိပြီး၊ **စာသား (str)**
သည်လည်း အညွှန်းဖြင့် ဖတ်နိုင်သော တန်ဖိုးဖြစ်သည်။ ဤစာမျက်နှာရှိ ```akk block တိုင်းကို
`akk` ဖြင့် တကယ် run စစ်ဆေးထားသည် — `cargo test --test docs_collections` က block တိုင်းကို
run ပြီး `# ရလဒ်:` / `# အမှား:` အောက်က စာသားနှင့် တိုက်စစ်သည်။

## ၁။ ခြုံငုံကြည့်ချက်

| # | အမျိုးအစား | မြန်မာ | ရေးပုံ | ပြောင်းလဲနိုင်? | ပုံနှိပ်ပုံ |
|---|---|---|---|---|---|
| 1 | list | **စာရင်း** | `[10, 20, 30]` | ✅ ပြောင်းနိုင် | `[10, 20, 30]` |
| 2 | tuple | **အစု** | `(1, 2, 3)` | ✅ အညွှန်းဖြင့် | `(1, 2, 3)` |
| 3 | set | **အုပ်စု** | `{1, 2, 3}` | ✅ အညွှန်းဖြင့် | `{1, 2, 3}` |
| 4 | dict | **အဘိဓာန်** | `{ "a" သည် 1 ဖြစ်၏။ }` | ✅ ပြောင်းနိုင် | `{"a": 1}` |
| 5 | table | **ဇယား** | `[[1, 2], [3, 4]]` | (list နှစ်ထပ်) | `[[1, 2], [3, 4]]` |
| + | string | **စာသား** | `"မြန်မာ"` | ❌ မပြောင်းနိုင် | `မြန်မာ` |

စုစည်းမှုတစ်ခုကို ကြေညာရန် `<name> မှာ <literal> ဖြစ်၏။` ကို သုံးသည်။

## ၂။ စာရင်း — list `[...]`

အသုံးအများဆုံး၊ **ပြောင်းလဲနိုင်သော** (mutable) array။ အညွှန်းသည် **0 မှ စ**သည်။
ဒြပ်စင်ကို `xs[i] သည် <value> ဖြစ်၏။` ဖြင့် အစားထိုးနိုင်သည်။

အညွှန်းဖြင့် ရေးသည့် စည်းမျဉ်းသည် **မရှိလျှင် ဖန်တီး၊ ရှိလျှင် အစားထိုး** ဖြစ်သည်။
`xs[i] က <value>။` တွင် `i` သည် ရှိပြီးသား နေရာ ဖြစ်လျှင် တန်ဖိုးကို အစားထိုးသည်၊
`i` သည် အရှည်နှင့် တူလျှင် (အဆုံး၏ နောက်တစ်နေရာ) ဒြပ်စင်အသစ် အဖြစ် ထပ်ထည့်သည်။
ထို့ထက် ကျော်လွန်၍ ကွက်လပ် မဖြစ်စေရန် `E049` ဖြစ်သည်။

```akk
xs မှာ [10, 20, 30] ဖြစ်၏။
xs ကို ဖော်ပြပါ။
xs[0] ကို ဖော်ပြပါ။
xs[0] သည် 99 ဖြစ်၏။
xs ကို ဖော်ပြပါ။
print(len(xs));
print(slice(xs, 1, 3));
print(sum(xs));
print(push(xs, 40));
print(xs);
print(pop(xs));
print(xs);
# ရလဒ်:
# [10, 20, 30]
# 10
# [99, 20, 30]
# 3
# [20, 30]
# 149
# 4
# [99, 20, 30, 40]
# 40
# [99, 20, 30]
```

```akk
xs မှာ [10, 20] ဖြစ်၏။
xs[0] က 99။
xs[2] က 30။
xs ကို ဖော်ပြပါ။
# ရလဒ်:
# [99, 20, 30]
```

`push` က စာရင်း၏ အရှည်သစ်ကို ပြန်ပေးပြီး၊ `pop` က ဖယ်ရှားလိုက်သော နောက်ဆုံးတန်ဖိုးကို
ပြန်ပေးသည်။ `sort`၊ `insert`၊ `remove`၊ `append` တို့သည် စာရင်းကိုယ်တိုင်ကို ပြောင်းလဲသည်
(`insert` က အရှည်သစ်၊ `remove` က ဖယ်ရှားလိုက်သည့် တန်ဖိုးကို ပြန်ပေးသည် — နမူနာကို
အပိုင်း ၉ တွင် ကြည့်ပါ)။

## ၃။ အစု — tuple `(...)`

ဖွဲ့စည်းပြီး တန်ဖိုးအစဉ် သတ်မှတ်ထားသော array။ အညွှန်းဖြင့် ဖတ်နိုင်သလို
**ရေးနိုင်သည်** — list နှင့် စည်းမျဉ်းတူသည် (ရှိလျှင် အစားထိုး၊ အဆုံးတွင် ဖန်တီး၊
ကျော်လျှင် `E049`)။

```akk
t မှာ (1, 2, 3) ဖြစ်၏။
t ကို ဖော်ပြပါ။
t[2] ကို ဖော်ပြပါ။
print(len(t));
print(reverse(t));
print(join(t, "-"));
# ရလဒ်:
# (1, 2, 3)
# 3
# 3
# (3, 2, 1)
# 1-2-3
```

```akk
t မှာ (1, 2) ဖြစ်၏။
t[1] က 9။
t[2] က 3။
t ကို ဖော်ပြပါ။
# ရလဒ်:
# (1, 9, 3)
```

`push`/`sort` ကဲ့သို့ စာရင်းအတွက် builtin များက tuple ကို လက်မခံပါ (အပိုင်း ၁၀)။

## ၄။ အုပ်စု — set `{...}`

ထပ်နေသော တန်ဖိုးများကို ဖျက်ပြီး **ထည့်သည့်အစဉ်အတိုင်း** သိမ်းသည်။
ဖတ်ရန် အညွှန်းလည်း ရသည် (`s[0]` သည် ပထမဆုံး ထည့်သည့် တန်ဖိုး)။

```akk
s မှာ {1, 2, 2, 3} ဖြစ်၏။
s ကို ဖော်ပြပါ။
print(len(s));
print(contains(s, 2));
print(join(s, ","));
print(slice(s, 1, 3));
x သည် s ထဲမှ တစ်ခုစီ
    x ကို ဖော်ပြပါ။
ပြီး။
# ရလဒ်:
# {1, 2, 3}
# 3
# True
# 1,2,3
# [2, 3]
# 1
# 2
# 3
```

set တွင် အညွှန်းဖြင့် ရေးလျှင် အနေအထားကို အသုံးပြုသည် — ရှိပြီးသား နေရာ ဖြစ်လျှင်
အစားထိုးသည်၊ အဆုံးတွင် ဖန်တီးသည်၊ ကျော်လျှင် `E049`။ set သည် တန်ဖိုးတူ နှစ်ခု မထားသဖြင့်
ရေးလိုက်သော တန်ဖိုးသည် အခြားနေရာတွင် ရှိပြီးသား ဖြစ်လျှင် ရေးလိုက်သည့် နေရာကို ဖယ်ပြီး
မူလနေရာကို ထိန်းထားသည်။

```akk
s မှာ {1, 2} ဖြစ်၏။
s[0] က 7။
s[2] က 3။
s ကို ဖော်ပြပါ။
s[0] က 3။
s ကို ဖော်ပြပါ။
# ရလဒ်:
# {7, 2, 3}
# {2, 3}
```

`slice` သည် set ဖြစ်လျှင်ပင် **list** ကို ပြန်ပေးသည်။ `reverse` က set ကို လက်မခံပါ
(list/tuple/စာသား သာ — အပိုင်း ၁၀)။

## ၅။ အဘိဓာန် — dict `{ key သည် value ဖြစ်၏။ }` / `{ key က value။ }`

key–value အတွဲများ၊ **ထည့်သည့်အစဉ်** ထိန်းထားသည်။ key အသစ် ရေးလျှင် ထည့်သည်၊
ရှိပြီးသား key ရေးလျှင် တန်ဖိုးကို အစားထိုးသည်။

entry တစ်ခုစီကို `"key" က value။` ဖြင့် အတိုကောက် ရေးနိုင်ပြီး ကြေညာချက်ကို
`အဘိဓာန် <name> က <literal>။` ဖြင့်လည်း ရေးနိုင်သည်။

```akk
အဘိဓာန် e က { "a" က 1။ "b" က 2။ }။
e ကို ဖော်ပြပါ။
# ရလဒ်:
# {"a": 1, "b": 2}
```

```akk
d မှာ { "a" သည် 1 ဖြစ်၏။ "b" သည် 2 ဖြစ်၏။ } ဖြစ်၏။
d ကို ဖော်ပြပါ။
d["b"] ကို ဖော်ပြပါ။
d["b"] သည် 9 ဖြစ်၏။
d["c"] သည် 3 ဖြစ်၏။
d ကို ဖော်ပြပါ။
print(keys(d));
print(values(d));
print(entries(d));
print(contains(d, "a"));
k သည် d ထဲမှ တစ်ခုစီ
    k ကို ဖော်ပြပါ။
ပြီး။
# ရလဒ်:
# {"a": 1, "b": 2}
# 2
# {"a": 1, "b": 9, "c": 3}
# ["a", "b", "c"]
# [1, 9, 3]
# [("a", 1), ("b", 9), ("c", 3)]
# True
# a
# b
# c
```

dict ကို `for` ဖြင့် လှည့်လျှင် **key** များ ရသည်။ `values(d)` ကို လှည့်လျှင် တန်ဖိုးများ
ရသည်။

## ၆။ ဇယား — table (list နှစ်ထပ်)

`ဇယား` သည် သီးခြား runtime အမျိုးအစား မဟုတ်ဘဲ **list of lists** ဖြစ်သည်။
အညွှန်းကို ဆက်ရေးနိုင်သည်။

```akk
grid မှာ [[1, 2], [3, 4]] ဖြစ်၏။
grid[0][1] ကို ဖော်ပြပါ။
grid[1] ကို ဖော်ပြပါ။
# ရလဒ်:
# 2
# [3, 4]
```

## ၇။ စာသား — str (array ကဲ့သို့)

အညွှန်းနှင့် `len` သည် **byte** မဟုတ်၊ **မြန်မာစာလုံး (grapheme cluster)** အလိုက် ဖြစ်သည်။
`မြန်မာ` တွင် စာလုံး ၃ လုံး ရှိသည်။

```akk
w မှာ "မြန်မာ" ဖြစ်၏။
w[0] ကို ဖော်ပြပါ။
print(len(w));
print(slice(w, 1, 3));
x သည် w ထဲမှ တစ်ခုစီ
    x ကို ဖော်ပြပါ။
ပြီး။
# ရလဒ်:
# မြ
# 3
# န်မာ
# မြ
# န်
# မာ
```

## ၈။ လှည့်ပတ်ခြင်း (iteration)

စုစည်းမှုတိုင်းနှင့် စာသားအတွက် ပုံစံတူသည် — `x သည် <collection> ထဲမှ တစ်ခုစီ`။
ကိန်းအပိုင်းအခြားအတွက် အဆုံးသည် **မပါ**ဘဲ၊ အဆင့်ကို `တိုးခြင်းဖြင့်` ဖြင့် ပေးသည်။

```akk
i သည် 0, 6 ထဲမှ တစ်ခုစီ 2 တိုးခြင်းဖြင့်
    i ကို ဖော်ပြပါ။
ပြီး။
# ရလဒ်:
# 0
# 2
# 4
```

## ၉။ စုစည်းမှု builtin များ

| builtin | လက်ခံသည် | ပြန်ပေးသည် |
|---|---|---|
| `len(x)` | စာသား သို့မဟုတ် စုစည်းမှု | အရှည် (စာလုံး / အရေအတွက်) |
| `contains(xs, v)` | စာသား/စုစည်းမှု, တန်ဖိုး | `True` / `False` |
| `slice(xs, start[, end])` | စာသား/list/tuple/set | အစိတ်အပိုင်း အသစ် (set ဖြစ်လျှင် list) |
| `reverse(xs)` | စာသား/list/tuple | အစဉ်ပြောင်းထားသော မိတ္တူ |
| `join(xs, sep)` | စာသား/စုစည်းမှု, စာသား | စာသား |
| `sum(xs)` | ကိန်းများ ပါသော စုစည်းမှု | ကိန်း |
| `enumerate(xs)` | စုစည်းမှု | `(index, value)` list |
| `map` / `filter` / `reduce` | စုစည်းမှု, callback | list / တန်ဖိုး |
| `keys` / `values` / `entries` | dict | list |
| `push` / `append` / `pop` / `insert` / `remove` / `sort` | **list** သာ (ပြောင်းလဲသည်) | အရှည် / တန်ဖိုး / list |

```akk
xs မှာ [3, 1, 2] ဖြစ်၏။
print(sort(xs));
print(xs);
print(insert(xs, 1, 9));
print(remove(xs, 0));
print(xs);
print(enumerate(xs));
print(map(xs, fn(x) { x * 2 }));
print(filter(xs, fn(x) { x > 1 }));
print(reduce(xs, fn(a, b) { a + b }, 0));
# ရလဒ်:
# [1, 2, 3]
# [1, 2, 3]
# 4
# 1
# [9, 2, 3]
# [(0, 9), (1, 2), (2, 3)]
# [18, 4, 6]
# [9, 2, 3]
# 14
```

## ၁၀။ အမှားကုဒ်များ — အညွှန်း၊ အမျိုးအစား၊ ပြောင်းလဲမှု

အညွှန်းသည် အကွာအဝေးပြင်ပ ဖြစ်လျှင် `E049` ဖြစ်သည်။ အနုတ်အညွှန်း မရပါ။

```akk
xs မှာ [1, 2, 3] ဖြစ်၏။
xs[5] ကို ဖော်ပြပါ။
# အမှား:
# E049 လိုင်း 2 တွင် အညွှန်း 5 သည် အကွာအဝေးပြင်ပတွင် ရှိနေပါသည်။
```

```akk
xs မှာ [1, 2, 3] ဖြစ်၏။
xs[-1] ကို ဖော်ပြပါ။
# အမှား:
# E049 လိုင်း 2 တွင် အညွှန်း -1 သည် အကွာအဝေးပြင်ပတွင် ရှိနေပါသည်။
```

list အတွက် builtin ကို အခြား အမျိုးအစားဖြင့် ခေါ်လျှင် `E110` ဖြစ်သည်။

```akk
t မှာ (1, 2, 3) ဖြစ်၏။
print(push(t, 4));
# အမှား:
# E110 လိုင်း 2 တွင် push() စာရင်း လိုအပ်ပါသည်၊ အစု ရပါသည်
```

```akk
s မှာ {1, 2} ဖြစ်၏။
print(reverse(s));
# အမှား:
```

## ၁၁။ သတိထားရန်

### ၁၁.၁ အမျိုးအစား စစ်ဆေးခြင်းတွင် စုစည်းမှုများ မပါ

`အကယ်၍`/`အခြေအနေ` ၏ အခြေအနေတွင် စစ်နိုင်သည့် အမျိုးအစားများမှာ `စာသား`၊ `ကိန်း`၊
`ဒဿမကိန်း`၊ `မှန်/မှား` သာ ဖြစ်သည်။ `(xs သည် စာရင်း)` ကဲ့သို့ ရေးလျှင် `E012` ဖြစ်သည်။

```akk
xs မှာ [1, 2] ဖြစ်၏။
အကယ်၍ (xs သည် စာရင်း) ဖြစ်လျှင်
    "list" ကို ဖော်ပြပါ။
ပြီး။
# အမှား:
# E012 လိုင်း 2 တွင် အခြေအနေ ရေးသားပုံ မှားနေပါသည်။ အသုံးပြုပုံ — (<value> <တန်ဖိုးနှိုင်းယှဉ်ခြင်း> <value>) (နှင့်|သို့) (...) ဖြစ်လျှင်
#
# line 2| အကယ်၍ (xs သည် စာရင်း) ဖြစ်လျှင်
#              ↑
#              |
#              |
#         အခြေအနေ ရေးသားပုံ မှား
```

### ၁၁.၂ `akk build` တွင် စုစည်းမှု အချို့ မထောက်ပံ့သေး

Native backend (`akk build <file>`) သည် စာရင်း၊ အစု၊ အုပ်စု၊ အဘိဓာန် literal၊ ၎င်းတို့၏
index/`len`/print၊ `for` ဖြင့် စုစည်းမှုကို လှည့်ပတ်ခြင်း (iteration) နှင့် index ဖြင့်
တန်ဖိုးပြောင်းခြင်း (`xs[i] က v။`) ကို ထောက်ပံ့ပြီးဖြစ်သည်။ ရေးလိုက်တိုင်း collection အသစ်တစ်ခု
ဖန်တီးပြီး ကိန်းရှင်ထဲ ပြန်ထည့်သဖြင့် interpreter ကဲ့သို့ **value semantics** ရှိသည် —
`ys မှာ xs ဖြစ်၏။` ပြီးနောက် `ys[0]` ကို ရေးလျှင် `xs` မပြောင်းပါ။
အဘိဓာန်ကို လှည့်လျှင် key များ ရသည်။ စုစည်းမှု နှစ်ခုကို `==`/`!=` ဖြင့် နှိုင်းယှဉ်ခြင်းကိုလည်း
ထောက်ပံ့သည် — အမျိုးအစား၊ အရှည်နှင့် ဒြပ်စင် (အဘိဓာန်ဆိုလျှင် key/value အတွဲ) အားလုံး
အစဉ်အတိုင်း တူမှ ညီသည်ဟု ဆိုသည် (ပုံနှိပ်ပုံနှင့် တူညီသော စည်းမျဉ်း)။
စုစည်းမှုထဲ စုစည်းမှု ထည့်ထားလျှင်လည်း အလွှာမည်မျှပဲ ရှိရှိ ရနိုင်သည် — `grid[0][1]`၊
`deep[0][1][0]`၊ အဘိဓာန်ထဲ စာရင်း၊ nested `for` စသည်တို့ဖြစ်သည်။ analyzer က binding တိုင်း
နှင့်အတူ **element shape** (ဒြပ်စင်၏ အမျိုးအစားနှင့်၊ ၎င်းကိုယ်တိုင် စုစည်းမှုဖြစ်လျှင် ၎င်း၏
ဒြပ်စင် shape) ကို သယ်ဆောင်သောကြောင့်ဖြစ်သည်။ ထို shape သည် လုပ်ဆောင်ချက် ခေါ်ခြင်းကို
ဖြတ်သန်းသည် — parameter သို့ ပေးလိုက်သော စုစည်းမှု၏ shape က callee ထဲတွင် ရိုက်ထည့်ပြီး၊
ပြန်ပေးလိုက်သော စုစည်းမှု၏ shape က caller ဆီ ရောက်သဖြင့် ခေါ်ဆိုမှု၏ ရလဒ်ကို index
ပြုလုပ်နိုင်သည်။ parameter တစ်ခုသည် shape တစ်ခုတည်းသာ ရနိုင်သည်; call site နှစ်ခုက
shape မတူလျှင် `E177` ဖြင့် ငြင်းသည်။
`for i in n` တွင် `n` ကို ကိန်းဖြစ်လျှင်လည်း interpreter ၏ auto-range အတိုင်း
`0, 1, ...` ကို `n` အောက်အထိ လှည့်ပြီး (float ဖြစ်လျှင် အပေါင်းဖက် ဝိုင်းချ၊ သုည/အနုတ်
ဖြစ်လျှင် တစ်ခါမှ မလှည့်) loop ကိန်းရှင်သည် အမြဲ `int` ဖြစ်သည်။

**compile-time တွင် သိသော စာသား** အတွက် `len(s)`၊ `for ch in s` နှင့် `s[i]` ကို
နိုင်ပြီဖြစ်သည် — compiler ကိုယ်တိုင် (interpreter ၏ `text` module ဖြင့်) grapheme cluster
များကို တွက်ပြီး int ကိန်းသို့မဟုတ် cluster စာရင်းအဖြစ် ပြောင်းပေးသဖြင့် `မြန်မာ` သည်
ခြောက်လုံးမဟုတ် သုံးလုံးဖြစ်ပြီး အကွာအဝေးပြင်ပ index သည် interpreter နည်းတူ `E049`
(လိုင်းအပါအဝင်) ဖြစ်သည်။ run time တွင်မှ ရောက်လာသော စာသား (parameter၊ လုပ်ဆောင်ချက်
ရလဒ်) အတွက် ထို သုံးမျိုးကို native runtime တွင် Unicode table မရှိသဖြင့် `E177` ဖြင့်
ငြင်းသည်။
စာသားထဲ အက္ခရာရေးခြင်း၊ nested element ထဲ ရေးခြင်း (parser ကိုယ်တိုင် `E001` ဖြင့် ငြင်းသည်) နှင့်
ဒြပ်စင် အမျိုးအစား ရောထည့်ခြင်းတို့ကို မထောက်ပံ့သေးဘဲ `E177` ဖြင့် ငြင်းသည်။
`push`/`append`၊ `pop`၊ `insert`၊ `remove` နှင့် `sort` တို့ကို ယခု `akk build` တွင်လည်း
သုံးနိုင်ပြီး — `sort` က int/float/string စာရင်းအတွက် stable ascending အစဉ်ဖြစ်သည်။
အလွတ်စာရင်းမှ `pop` နှင့် စာရင်းအပြင်ဘက် အညွှန်းတို့သည် interpreter ၏ `E110`/`E049`
ဖြစ်ပြီး၊ call တွင် line မသယ်ဆောင်သဖြင့် လိုင်းအပိုင်းသာ မပါပါ။
အလွတ် စုစည်းမှုအဖြစ် စတင်ခဲ့သော အတွင်းပိုင်း စုစည်းမှုကို ထပ်မံ index လုပ်ခြင်းကိုလည်း
(ဒြပ်စင် အမျိုးအစား မသိနိုင်သေးသဖြင့်) `E177` ဖြင့် ငြင်းသည်။ စုစည်းမှုကို အစဉ်လိုက် နှိုင်းယှဉ်ခြင်း (`<`, `>`) သည် interpreter
နည်းတူ `E042` ဖြစ်ပြီး native တွင်လည်း တူညီသော စာသား၊ လိုင်းနှင့် exit 1 ဖြစ်သည်။
ဤစုစည်းမှုများကို `akk` interpreter/VM တွင် အပြည့်အဝ သုံးနိုင်သည်။
