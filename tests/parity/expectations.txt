# Native parity expectations.
#
# One line per fixture in tests/fixtures/, tab-separated:
#
#   <name>	match
#       The native build must succeed and its exit status, stdout and stderr
#       must equal the interpreter's. `Wxxx` warning lines and the
#       timing-dependent "Compiled in ..." line are ignored.
#
#   <name>	refuse	<keyword>	[<keyword> ...]
#       The native build must fail with an Exxx diagnostic that contains every
#       keyword. A compiler panic does not count as a refusal.
#
# A refusal is recorded only when the native backend honestly says it cannot
# compile the program yet; a silently dropped statement or a wrong answer is a
# failure, not a refusal.
#
# Index-based mutation (`xs[i] = v`) does not flip any fixture here: no
# fixture in tests/fixtures/ writes through an index (destructure_forms.akk
# assigns a whole list to a pattern, not to an element), and the collection
# fixtures stay refused for other constructs. The native-only fixture
# tests/native/fixtures/mutation.akk covers the write forms and is compared
# with the interpreter by tests/native/main.rs under both optimiser modes.
